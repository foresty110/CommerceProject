# 자바 콘솔 기반 커머스 시스템 

## 프로젝트 개요
이 프로젝트는 순수 자바(Java)를 활용하여 콘솔 환경에서 작동하는 간단한 커머스 시스템을 구현한 과제입니다. 
품, 카테고리, 고객, 주문 등 다양한 객체가 서로 협력하여 동작하는 객체 지향 설계를 콘솔 커머스 플랫폼에 적용해보는 경험을 쌓는 것이 목표입니다. 

---

## 학습 목표
**1. 객체 지향 프로그래밍 설계 및 구현**
- Product, Customer, Cart 등 핵심 기능을 담당하는 클래스들을 정의하고, 각 객체 간의 역할과 협력을 명확히 구분하여 설계합니다.

**2. 사용자 인터페이스 및 흐름 제어**
- 콘솔 입출력을 통해 사용자에게 메뉴를 제공하고, 입력값의 유효성 검사를 통해 프로그램의 안정성을 확보합니다.
- CommerceSystem 클래스에서 전체 프로그램의 흐름을 제어하고, 각 메뉴에 따른 실행 동작을 관리하는 로직을 구현합니다.

**3. 컬렉션 프레임워크 활용**
- ArrayList를 사용하여 상품 목록, 장바구니 목록 등 다양한 데이터를 효율적으로 저장하고 관리합니다.

---

## 개발 환경
- Java 17
- IntelliJ IDEA
  
---

## 주요 기능
**1. 사용자 모드 기능**
- 상품 카테고리 및 목록 조회: 카테고리에 속하는 상품 목록을 조회할 수 있습니다. 
- 가격대별 필터링: 특정 조건을 만족하는 상품 목록을 필터링하여 조회할 수 있습니다.
- 장바구니 기능: 상품을 장바구니에 추가하고, 수량을 누적하며, 목록을 확인할 수 있습니다.
- 주문 및 결제: 장바구니 상품에 대해 고객 등급별 할인율을 적용한 최종 금액을 확인하고 주문을 확정합니다. 주문 확정 시 상품의 재고가 차감됩니다.
- 주문 취소: 진행 중인 주문을 취소하고 장바구니를 비웁니다.

**2. 관리자 모드 기능**
- 비밀번호 인증: 관리자 모드 접속 시 정해진 비밀번호를 통해 인증해야 접근 가능합니다.
- 상품 추가: 선택한 카테고리에 상품 정보를 입력하여 새 상품을 등록합니다.
- 상품 수정: 기존 상품의 정보를 수정합니다.
- 상품 삭제: 카테고리 내 특정 상품을 삭제하며, 장바구니에도 담겨 있다면 함께 제거합니다.

## 폴더 구조
```
📁 commerce
└── 📁 src
    └── 📁 commerce
        ├── 📄 Main.java (메인 실행 클래스)
        ├── 📄 CommerceSystem.java (전체 시스템 제어, 비즈니스 로직)
        ├── 📄 Product.java (상품 정보)
        ├── 📄 Category.java (상품 카테고리 및 상품 목록 관리)
        ├── 📄 Cart.java (장바구니 로직)
        ├── 📄 CartItem.java (장바구니 내 상품 항목)
        ├── 📄 Customer.java (고객 정보)
        ├── 📄 CustomerGrade.java (고객 등급 및 할인율 Enum)
        ├── 📄 Menu.java (메뉴 UI 및 사용자 입력 처리)
        ├── 📄 MenuType.java (메뉴 종류 Enum)
        ├── 📄 MenuActionType.java (메뉴 동작 종류 Enum)
        └── 📄 ScannerSystem.java (사용자 입력 유효성 검사 유틸리티)
```

---

## 실행 방법
1. Main.java 파일을 실행합니다.
2. 콘솔에 출력되는 메뉴 안내에 따라 번호를 입력하여 프로그램을 사용합니다.
3. 관리자 모드는 비밀번호 admin123을 입력하여 사용합니다.
